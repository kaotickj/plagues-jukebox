# K-Tunes Android 0.1.1

- Rebrand launcher, interface, About, notices and playlist export filename to K-Tunes.
- Filter automatic device scans by music/system-sound/voice-recording flags and
  recognizable voicemail or recording paths and filenames.
- Add optional minimum scan durations, off by default to retain short songs.
- Remove rejected previous device imports from the catalog and queue on rescan,
  while retaining manually imported tracks and leaving source files untouched.
- Preserve the application ID, signing key, saved catalog, queue and corrected tags.
